# NLP Kelompok 3A — AI Smart Learning Assistant

Proyek akhir mata kuliah Natural Language Processing.

## Fokus Sistem

- Text Summarization.
- Question Generation berdasarkan tiga kategori literasi.
- Feedback jawaban berbasis materi sumber.
- Antarmuka Streamlit.

## Dataset UTBK Bersama

Dataset UTBK asli tersedia di repository bersama:
https://github.com/dinaarimaya09/datasetNLPkelompok3

File sumber:
- BaseSoalLBI.xlsx
- BaseSoalLBI2.xlsx

Dataset asli tidak diubah. Salinan bersih dan contoh soal terpilih
disimpan di folder data/utbk_processed/.

## Kategori Literasi

1. Menemukan Informasi.
2. Memahami Informasi.
3. Mengevaluasi dan Merefleksi Informasi.

## Materi Pembelajaran

PDF materi tambahan tersedia di data/raw_materials/.
Metadata dan sumber materi dicatat di data/materi_index.csv.
